# Gameplay Fixtures

Durable package-level deterministic fixtures belong here. Browser/testbed-only fixtures remain under `.testbed/fixtures/`.

- `task11-prototype-profiles-v1.json` is the exact six-profile experimental default bundle. Profile hashes bind canonical identity and settings; the bundle hash binds the sorted exported bundle body.
- `task11-prototype-replay-v1.json` declares the content-hashed Flow/four-Boxing candidate and safety/modifier/shadow replay matrix exercised by `scripts/validate-task11-prototype-replay.js`.
